# 💰 SpendSense - Personal Expense Dashboard

## 📌 Project Overview
SpendSense is a Power BI dashboard designed to analyze personal income, expenses, savings, budget utilization, and financial risk levels. The dashboard provides interactive insights to help users track spending habits and make informed financial decisions.

## 📊 Dashboard Preview

(SpendSence Dashbord.png)

## 🚀 Features

- Total Expense Analysis
- Total Income Tracking
- Net Savings Calculation
- Average Monthly Expense
- High Risk User Monitoring
- Monthly Expense Trend Analysis
- Expense Category Breakdown
- City-wise Expense Distribution
- Payment Method Analysis
- Age Group Spending Analysis
- Budget vs Actual Expense Comparison
- Budget Risk Level Assessment

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- MySQL
- Python (Pandas)
- CSV Dataset

## 📂 Repository Contents

- `SpendSense.pbix` - Power BI Dashboard File
- `SpendSense_Cleaned.csv` - Cleaned Dataset
- `SpendSenseDB.sql` - MySQL Database Script
- `SpendSense Dashboard.PNG` - Dashboard Screenshot

## 📈 Key Insights

- Identifies spending patterns across categories.
- Compares actual expenses with allocated budgets.
- Highlights high-risk users based on spending behavior.
- Tracks monthly savings and income trends.
